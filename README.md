# SofTime Windows — actualizaciones

Canal público de instaladores para Windows 11 de 64 bits. El código fuente y los datos comerciales no se publican aquí.

## Instalación inicial

Descarga **SofTimeWindows-win-Setup.exe** desde [la versión publicada](https://github.com/luisfe1503-star/SofTimeWindowsUpdates/releases/latest). Cierra SofTime normalmente y ejecuta el instalador. Conserva tus datos y credenciales existentes.

## Siguientes actualizaciones

Desde la pantalla inicial de SofTime pulsa **Buscar actualizaciones**. Si hay una versión nueva, descarga el paquete y utiliza la opción para reiniciar e instalar cuando hayas terminado el trabajo abierto.

El canal verifica un catálogo firmado y la integridad del paquete. No requiere credenciales de GitHub en la caja. Mantiene una instalación activa; puede conservar un paquete de mantenimiento y archivos temporales durante la actualización.

El instalador todavía no tiene firma de editor Authenticode. La firma del canal no sustituye esa certificación ni elimina posibles avisos de Windows. No desactives las protecciones del equipo.
